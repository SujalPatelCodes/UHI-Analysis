================================================================================
 TIPS
================================================================================
- Each command creates its own output folder — use a unique --outputs path
  per run to avoid overwriting results.

- Use --no-tune for faster runs; omit it to enable grouped Random Forest
  hyperparameter search (slower but potentially better model accuracy).

- Pass --index-diagnostics to estimate how many observations would be masked
  if negative reflectances were rejected (adds extra Earth Engine computation).

- LANDSAT source supports --resolution down to 30 m, but true thermal detail
  is limited by TIRS band resolution (~100 m). Use 500-1000 m for reliable
  spatial statistics over a city-scale ROI.

- If a city geocode returns a region that is too large or crosses the
  antimeridian, supply explicit --roi-bounds west south east north.

- Results are saved in summary.json. Check the "status" field:
    "complete"  -- all years and the ML step succeeded
    "partial"   -- some years succeeded; check "failures" key
    "failed"    -- no year data was produced

- The interactive HTML maps (e.g. mumbai_2022_interactive_map.html) require
  an internet connection to load Earth Engine tile layers. Open them in any
  modern web browser.
