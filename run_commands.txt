PREREQUISITES (Run once in PowerShell)
--------------------------------------
1. Navigate to your project folder:
   cd D:\Project\UHI-Analysis-main

2. Activate virtual environment:
   .\.venv\Scripts\Activate.ps1

3. Verify Earth Engine authentication:
   python -c "import ee; ee.Initialize(project='uhi-analysis-project'); print('Connected!')"

================================================================================
 HELPFUL CLI OPTIONS & FLAGS
================================================================================
--city "Name"             City to geocode using OpenStreetMap Nominatim
--roi-bounds W S E N      Custom bounding box (avoids geocoder, reproducible)
--years 2022 2023         One or more analysis years (>= 2013)
--source MODIS|LANDSAT    Primary thermal sensor (MODIS Terra or Landsat 8)
--resolution 1000         Output analysis grid in meters (MODIS: 1000-2000, Landsat: 30-2000)
--no-tune                 Skips slow Random Forest hyperparameter tuning (recommended for quick runs)
--index-diagnostics       Estimates negative-input mask sensitivity
--clusters auto|2|3|4|5   Temperature zone clustering (auto uses silhouette score)
--outputs outputs/path    Folder to store maps, figures, CSVs, and summary.json
--help                    Displays full manual of all available options
